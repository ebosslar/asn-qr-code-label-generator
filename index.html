QR Code Label Generator for ASNs in Paperless-ngx

This tool generates QR code labels for the Archive Serial Number (ASN) feature in Paperless-ngx. It's a (quick'n'dirty) fork of asn-qr-code-label-generator by Tobias L. Maier which hereby has been tweaked to meet my very own personal needs. Therefore for anybody else I highly recommend to not use this instance, but the original QR Code Label Generator for ASN in Paperless-ngx instead!

I use some colored label ("mark"), for example, for my children's names (together with dedicated number ranges) so that I can give them their documents when they move out. I do the same for different storage locations (e.g., for particularly important documents that are stored in a fireproof safe). This mark allows me to see which stickers I use for what, without having to remember the number ranges.

One known limitation of this tool is that it only works on Google Chrome and possibly Firefox. This is because it uses the @page CSS rule to control the page size, margin, and to turn off the default header and footer of the browser. DOES NOT WORK IN SAFARI!

This mark gets printed on top of the ASN, but is not encoded into the QR Code.

Formatting is to fit on Avery L4731REV-25 labels (7 x 27 = 189 sticker per sheet). Enter here the number for this batch to start with (next sheet should then start at 190).

This may be useful for debugging or to calibrate the print out.
